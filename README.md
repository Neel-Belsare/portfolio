# Neel Belsare — Cinematic Portfolio

A high-performance, dark-themed personal portfolio website featuring an immersive welcome animation video, dynamic portrait reveal, interactive tech matrix, and showcase of engineering projects and activity.

## ✨ Features
- **Cinematic Video Intro**: Autoplay background video with ambient audio, audio toggle, play/pause controls, and kinetic typography.
- **Signature Name Reveal**: High-contrast editorial layout with cutout portrait and signature cursive typography.
- **Interactive About Me**: Real-time typewriter narrative bio, headshot showcase, and experience counters.
- **Interactive Tech Stack Matrix**: Categorized grid with glowing Devicon badges.
- **Experience Timeline**: Vertical glowing timeline of roles and contributions.
- **Projects Showcase**: Filterable project gallery (AI, SaaS, Full Stack, Frontend) with case study links.
- **Beyond The Code**: GitHub metrics, streak counters, and LeetCode ratings.
- **Contact System**: Glassmorphic fixed navigation and interactive "Let's Talk" contact modal.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Devicon & Lucide React
- **Typography**: Orbitron, Dancing Script, Inter
- **Language**: TypeScript

## 🚀 Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
